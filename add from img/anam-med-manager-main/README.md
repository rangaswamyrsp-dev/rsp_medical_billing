UI Design Guidelines

Style: Modern, minimal, business-focused desktop application.

Layout: Fixed left navigation with a clean top header and spacious content area.

Colors:

White (#FFFFFF) for backgrounds.

Light Green (#22C55E) for primary actions and success indicators.

Blue (#2563EB) for navigation highlights and links.

Orange (#F59E0B) only for warnings, alerts, and important highlights.

Typography: Segoe UI or Poppins, 14–16 px for readability.

Icons: Simple line icons with consistent sizing.

Cards: Rounded corners (8–10 px), subtle shadows, generous spacing.

Performance: Prioritize fast loading and keyboard-friendly workflows for billing operators. demo login anam@2026 manjju@anam.com and main focus on billing interface for home page use side manu nav seach profile edit 3 dots and FAB for chat help sheet

This PRD is suitable as the foundation for a professional desktop application for ANAM Medical Store and can later be extended into a multi-branch enterprise medical management system.
